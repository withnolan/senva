01 / English

Terms of use

SENVA is an early-stage project by Shengyu Nolan Chen and Santiago Muñoz Veguillas. This website presents an idea and research hypotheses. SENVA is not presented as an incorporated company.

Idea / Hypothesis validation. The illustrations, captions and 3D scenes explain a concept. They do not demonstrate working recognition or translation. There is no prototype, confirmed research result or product for sale.

This is an informational website, with no purchases, accounts or service contracts. Use it lawfully, respect image rights and applicable content licences, and do not interfere with its security or operation. External websites have their own terms. Questions or corrections can be sent to either founder through the LinkedIn profiles above.

Privacy

The website code has no forms, analytics, advertising trackers, camera access or microphone access. Its fonts, illustrations, libraries and models are hosted with the site. The language preference described below stays in your browser; this code does not send it to the team.

Hosting is provided by GitHub Pages. GitHub records visitors’ IP addresses for security, including visits made without a GitHub account. See GitHub Pages data collection and GitHub’s privacy statement for its processing, retention and rights request channels.

LinkedIn and other external links open third-party services only when followed. Their privacy policies apply there. If you contact the founders on LinkedIn, your message is handled through that service. For questions about this website, use the founders’ profiles above.

Cookies & preferences

SENVA’s website code does not set cookies. It uses one functional browser-storage entry to remember a language you select. No advertising or analytics storage is added.

Name & technology
senva-language · localStorage
Purpose & value
Remember your EN/ES selection, stored as en or es.
Duration
No automatic expiry. It remains until you or your browser clear the stored site data.
Control
Change the language with EN/ES. To remove the saved choice, clear site data for this website in your browser settings. Blocking storage leaves the website readable, but the choice may not be remembered.

A language preference chosen by the visitor and used only for that purpose is an exempt preference under the AEPD cookie guidance. There is no optional tracking to accept or reject in this version.

Términos de uso

SENVA es un proyecto en fase inicial de Shengyu Nolan Chen y Santiago Muñoz Veguillas. Esta web presenta una idea e hipótesis de investigación. SENVA no se presenta como empresa constituida.

Idea / Validación de hipótesis. Las ilustraciones, los subtítulos y las escenas 3D explican un concepto. No demuestran reconocimiento ni traducción funcionales. No hay prototipo, resultados de investigación confirmados ni producto a la venta.

Es una web informativa, sin compras, cuentas ni contratación de servicios. Utilízala de forma lícita, respeta los derechos de imagen y las licencias aplicables a los contenidos y no interfieras con su seguridad o funcionamiento. Las webs externas tienen sus propias condiciones. Puedes enviar consultas o correcciones a cualquiera de los fundadores mediante los perfiles de LinkedIn anteriores.

Privacidad

El código de esta web no incorpora formularios, analítica, rastreadores publicitarios ni acceso a cámara o micrófono. Sus fuentes, ilustraciones, bibliotecas y modelos se alojan con la propia web. La preferencia de idioma descrita abajo permanece en tu navegador; este código no la envía al equipo.

El alojamiento lo proporciona GitHub Pages. GitHub registra las direcciones IP de las visitas por seguridad, incluso sin una cuenta de GitHub. Consulta la información de GitHub Pages sobre recogida de datos y la política de privacidad de GitHub para conocer sus tratamientos, conservación y vías de ejercicio de derechos.

LinkedIn y los demás enlaces externos abren servicios de terceros al seguirlos. Allí se aplican sus políticas de privacidad. Si contactas con los fundadores en LinkedIn, tu mensaje se gestiona en ese servicio. Para consultas sobre esta web, utiliza los perfiles anteriores.

Cookies y preferencias

El código de la web de SENVA no instala cookies. Utiliza una entrada funcional de almacenamiento del navegador para recordar el idioma que eliges. No añade almacenamiento publicitario ni de analítica.

Nombre y tecnología
senva-language · localStorage
Finalidad y valor
Recordar tu selección EN/ES, guardada como en o es.
Duración
Sin caducidad automática. Permanece hasta que tú o tu navegador borréis los datos guardados del sitio.
Control
Cambia el idioma con EN/ES. Para eliminar la elección guardada, borra los datos de esta web en los ajustes del navegador. Si bloqueas el almacenamiento, la web sigue siendo legible, aunque puede no recordar la elección.

La preferencia de idioma elegida por la persona visitante y utilizada solo con ese fin está exenta según la guía de cookies de la AEPD. En esta versión no hay rastreo opcional que aceptar o rechazar.
